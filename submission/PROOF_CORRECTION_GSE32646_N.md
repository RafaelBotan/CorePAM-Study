## Justification

The deposited GEO series GSE32646 (Miyake et al., 2012) contains **115 samples**
(verified directly from the GEO series matrix). The value "154" in the proof is a
typographical error in the cohort description.

This correction is **purely descriptive and changes no result**:

- The pCR results table already reports GSE32646 correctly as **N = 115** (27 pCR,
  23.5%; OR 2.10; AUC 0.716).
- All 115 eligible samples were analysed (100% CorePAM gene coverage), so the
  analysed N equals the cohort N.
- The pooled primary pCR analysis (total **N = 697** = 182 + 278 + 115 + 122) is
  unaffected, as are the pooled OR (1.69) and I² (0%).

No other text, table, figure, or numerical result requires modification.
